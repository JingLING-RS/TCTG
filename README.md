# TCTG: Task-Oriented Cross-Modal Trajectory Generation

Official repository for *Task-Oriented Cross-Modal Trajectory Generation for Land Cover Mapping With Missing Optical Observations: A Flood Case Study*.

**Release status:** The source code and processed dataset are planned for release upon acceptance of the manuscript. This repository currently provides the project information and release plan.

Data release is subject to applicable data-use and redistribution permissions. Details of the available data and access procedures will be provided at release.
